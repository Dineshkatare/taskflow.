# TaskFlow

A team task manager for **Android, iOS and Web**, built with Flutter from one codebase.

> 🚧 Work in progress — built step by step. See the commit history.

## Planned features
- Sign in with email or Google
- Projects and tasks with status, priority and due date
- Real-time updates for the whole team
- Works offline and syncs later
- English and Arabic (right-to-left) support
- Light and dark mode

## Tech stack
Flutter · Dart · Riverpod · go_router · Supabase · Drift · GitHub Actions

## Run locally
```bash
flutter pub get
flutter run
```

## Tests
```bash
flutter analyze
flutter test
```
